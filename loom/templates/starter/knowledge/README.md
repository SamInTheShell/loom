# Knowledge base

Plain-markdown reference material. Anything in this folder can be
searched from chats with `knowledge_search` and read with `read_file` -
and browsed or edited in the Library tab just the same.

Write every document as practice anyone can follow - a person at the
keyboard or a model in a chat executes the same steps. State what to do
and why it works; avoid addressing a particular kind of reader.

Organize however you like; folders are fine. Small focused files beat
one giant one - search returns file and line hits, and precise files make
precise hits.
