# Engineering practice

Language-agnostic engineering knowledge: how to plan, sequence, and
verify substantial software projects. Language-specific practice lives in
the separate `programming` repository (the Agent mode's default
specialization knowledge), under `<language>/`.

- **project-planning.md** - planning method for large builds: slicing
  work into verifiable milestones, gates, status tracking, and how to
  walk a big system through to completion without losing the thread.
  The worked example of this method is
  `go/distributed-kv/build-plan.md` in the `programming` repository.
